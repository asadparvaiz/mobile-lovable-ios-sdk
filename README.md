# MobileLovableKit

Precompiled SwiftUI components, services, navigation, and MVVM building blocks for Mobile Lovable generated iOS applications.

Add the package in Swift Package Manager and depend on the `MobileLovableKit` product. Version `0.2.1` supports iOS 16 and newer.

The implementation is distributed as an XCFramework; application repositories consume the compiled binary rather than the SDK source.
